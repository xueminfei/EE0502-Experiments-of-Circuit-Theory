## 🚀 食用指南

### 1. 获取资料
你可以直接点击页面右上角绿色的 `<> Code` 按钮，选择 **`Download ZIP`** 一键下载所有文件。或者，你也可以使用 Git 将仓库克隆到本地：

` ` `bash
git clone https://github.com/xueminfei/EE0502-Experiments-of-Circuit-Theory.git
` ` `

*(注：复制到你自己的文件时，请将上方 bash 代码块外层的三个反引号中间的空格去掉)*

### 2. 关于压缩包
仓库中包含几个 `.rar` 格式的压缩文件（如 `按实验整理.rar`），下载后请使用 WinRAR、7-Zip 等解压软件进行提取。

### 3. Git LFS 提示
由于仓库内含有较大的压缩包，我已经配置了 `.gitattributes` 并启用了 Git LFS (Large File Storage) 来管理大文件。如果你是通过命令行 `git clone` 下载，请确保你的电脑上已经安装了 [Git LFS](https://git-lfs.github.com/)，否则可能会拉取不到压缩包的完整内容。**直接下载 ZIP 则不受此影响。**
